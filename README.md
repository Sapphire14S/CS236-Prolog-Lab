## Laboratory Overview

This repository contains implementations of fundamental and advanced Prolog concepts including arithmetic reasoning, recursion, list manipulation, logical inference, symbolic computation, operator overloading, backtracking control, and declarative problem solving.

| Lab | Concepts Covered |

## Concepts Implemented

### Prolog Basics and Arithmetic

- Difference between:
  - `=`
  - `is`
  - `=:=`
- Arithmetic evaluation
- Variable unification
- Maximum number predicate
- Leap year checking
- Prime number checking
- Divisibility testing

### List Manipulation

- Membership checking
- Custom list length implementation
- Last element retrieval
- Element replacement in lists
- Palindrome detection
- Element retrieval by index
- List splitting using thresholds
- Head-tail recursive traversal

---

### Recursion and Mathematical Computation

- Fibonacci sequence generation
- Taylor series approximation for sine function
- Recursive arithmetic computation
- Power and factorial predicates

---

### Family Databases and Logical Inference

- Parent-child relationships
- Father relationship inference
- Sister relationship inference
- Grandmother relationship inference
- Birth-date databases

- Chronological reasoning

### Unary Arithmetic using Lists

- Unary number representation
- Successor computation

### Backtracking and Negation
