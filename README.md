## Assignment Overview

### Assignment 12 — Prolog Programming and Logic Implementation

The assignment focuses on implementing fundamental and advanced Prolog predicates involving recursion, arithmetic reasoning, list processing, symbolic logic, backtracking control, and custom operator definitions.

---

## Topics and Concepts Covered

### Prolog Basics and Arithmetic

- Difference between:
  - `=`
  - `is`
  - `=:=`
- Arithmetic evaluation in Prolog
- Variable unification
- Prime number checking
- Leap year detection
- Maximum of two numbers predicate

---

### List Manipulation

- Membership checking
- List length calculation
- Last element retrieval
- List replacement operations
- Palindrome checking
- Element access using indexing
- List splitting based on thresholds
- Recursive list traversal

---

### Recursion and Database Reasoning

- Fibonacci sequence implementation
- Taylor series approximation for sine function
- Family relationship database predicates:
  - father
  - sister
  - grandmother
- Birth-date reasoning
- Chronological comparison predicates

---

### Unary Arithmetic using Lists

- Unary number representation
- Successor predicate
- Recursive unary addition
- Arithmetic using symbolic lists

---

### Backtracking and Negation

- Duplicate removal using cuts (`!`)
- Deterministic predicates
- Negation as failure (`\+`)
- Single person detection
- Euclid’s Greatest Common Divisor (GCD) algorithm

---

### Operators and Advanced Logic

- Custom Prolog operator definitions
- Logical connectives:
  - negation
  - conjunction
  - disjunction
  - implication
- Expression parsing and evaluation
- Recursive arithmetic expression evaluation
- User-defined operators (`++`, `**`)

---

### Recursive Console Output

- Recursive square pattern printing
- Character-based output generation
